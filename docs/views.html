1. Effect Detail view

The main plugin workspace when an effect is selected. Rendered by EffectDetailView.

  • HeaderStripViewPersistent header band: IN pot / prev jog / category + title / next jog / OUT pot.
  • IN pot / OUT potInteractive RotaryPots (48pt). Vertical drag to change, double-tap to reset.
  • titleBig semibold effect name. Tap to open the browser.
  • category eyebrowSmall uppercase label above the title.
  • prev / next jog← PreviousName and NextName → buttons.
  • taglineCentered italic curly-quoted whatText.
  • chip rowSTEREO/MONO info chip left, filled theme + reset button chips right.
  • ParameterGrid1, 2, or 3 columns depending on parameter count.
  • ParameterRowCircled number + name + display value + slider. Numbers work for any count (1-37).
  • description areaScrollable text from awpdoc/<Effect>.txt. Hidden when identical to the tagline.

2. No Selection placeholder

Shown when no effect has been picked yet. Audio passes through. Rendered by NoSelectionView.

3. Browser / library

Full-screen 3-column library. Opened by tapping the title or the "Browse effects" button. Rendered by BrowserView.

  • SidebarViewFirst column (220pt). Collections + search + categories + Random + About.
  • close XTop-right of the sidebar. Dismisses the browser.
  • CollectionTabStripThree starred tabs: Recommended / Basic / Latest.
  • SearchFieldRounded pill search. Filters by name / category / whatText.
  • CategoryRowColored dot + name + (count) + chevron. Cyan accent when selected.
  • Random effect buttonPinned bottom. Picks a random effect from the filtered pool.
  • About Airwindows buttonPinned bottom. Opens AboutView as a sheet.
  • EffectListColumnMiddle column. Only shown once a category is picked.
  • NumberedEffectRow"1. Highpass" style row. Tap to highlight, tap again to select.
  • EffectPreviewColumnRight column. Grows to fill remaining space.
  • Select buttonBlue capsule top-right of the preview pane.
  • metadata pillsCategory / Mono / date pills under the tagline.

4. About sheet

Modal sheet from the sidebar's About button. Rendered by AboutView.

5. Host app additions

The standalone app embeds the same AirwindowsAUView but adds a floating audio passthrough toggle. Not visible when running as an AUv3 plugin.

  • speaker buttonAudio passthrough toggle. Mic → effect → speaker via AVAudioEngine.
